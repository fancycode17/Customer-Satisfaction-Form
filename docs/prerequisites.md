## Required software

**Python**
 - **Minimum version**: Python 3.12
 - Python must be installed and accessible from the command line so commands such as `python manage.py runserver` can be executed.
 - A compatible Python version needs to be used to create the virtual environment

To check the installed version run:
`python --version`
This should output Python 3.12 or a newer version.

**Git** <br><br>
Git is required if you intend to clone the repository or manage changes using Git.

To check whether Git is installed run:
`git --version`

## Optional - Development tools

**Visual Studio Code**<br><br>
Visual Studio Code is recommended for development but isn't required to run the application.

If using Visual Studio Code, the recommended extensions are:
- Python (ms-python.python)
- Pylance (ms-python.vscode-pylance)

These provide Python language support, as well as code completion and analysis.

## Python dependencies

The Python packages required by the application can be found in `requirements.txt`.

Follow the installation instructions to create a virtual environment and install the dependencies.
